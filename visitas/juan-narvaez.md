# Visita de Juan José Narváez (Equipo 1)

Lo que más me gustó de este repositorio: La organización limpia del proyecto, especialmente tener una carpeta `integrantes/` con un archivo individual para cada miembro (`jefferson.md`, `maicol.md` y `steveen.md`), lo que facilita navegar el repositorio y evita conflictos al trabajar en equipo.

Una sugerencia para mejorar el README: Como el archivo es corto, podrían ampliarlo agregando la estructura de carpetas del proyecto y enlaces directos hacia los perfiles dentro de `integrantes/`.

Un error que encontré: El archivo de configuración para ignorar archivos está nombrado como `git.gitignore` en lugar de `.gitignore`. Con ese nombre Git no aplica sus reglas; habría que renombrarlo a `.gitignore`.
